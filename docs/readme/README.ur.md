</details>

## پہلی بار چلانا

1. **ایپ کھولیں اور Google سے سائن اِن کریں۔** ٹیئر بیج (نیچے بائیں: **BASIC / PLUS / MAX**) آپ کے پلان کی تصدیق کرتا ہے۔
2. **جو ٹولز آپ استعمال کریں گے ان کے لیے اکاؤنٹس جوڑیں** (**ترتیبات** → متعلقہ اکاؤنٹ ٹیب):
   - **Flow اکاؤنٹس** → Flow تصویر / Flow ویڈیو
   - **Google اکاؤنٹس** → **Google Vids** اور **Google Pics** (دونوں صفحات یہی Google اکاؤنٹس شیئر کرتے ہیں؛ ہر اکاؤنٹ Vids ویڈیو کے لیے اور Pics تصاویر کے لیے الگ الگ آن کیا جاتا ہے)
   - **ChatGPT اکاؤنٹ** → GPT Image 2
   - **Vibes اکاؤنٹ** → Meta Vibes
   - **Grok اکاؤنٹ** → کوئی اکاؤنٹ پول نہیں: یہ ٹیب آپ کو **Auth Helper** براؤزر ایکسٹینشن انسٹال کرنے کے مراحل بتاتا ہے، پھر Grok آپ کے Chrome میں لاگ اِن `grok.com` ٹیب کے ذریعے چلتا ہے

   ہر اکاؤنٹ ٹیب اپنی ٹائٹل بار پر **"فعال: N اکاؤنٹس"** دکھاتا ہے تاکہ آپ جان سکیں کہ کتنے قابلِ استعمال ہیں۔
3. **بائیں سائیڈبار سے ایک صفحہ چنیں** اور بنانا شروع کریں۔ ہر جنریشن صفحہ ایک ہی تال رکھتا ہے: بائیں جانب پرومپٹ ٹائپ یا امپورٹ کریں، وہ دائیں جانب ایک **ٹیبل** میں آ جاتے ہیں، پھر **Run** دبائیں۔

ہر صفحے کے ہیڈر میں ایک لائیو **اسٹیٹس پٹی** ہوتی ہے - *چل رہے · قطار میں · مکمل · ناکام · اکاؤنٹس* - تاکہ آپ پورے بیچ کو ایک نظر میں دیکھ سکیں۔ کیو مینیجر کھولنے کے لیے **قطار میں** پر کلک کریں، اکاؤنٹ سیٹنگز پر جانے کے لیے **اکاؤنٹس** پر۔

## خصوصیات

![G-Labs Studio](../screenshots/en/flow-image.webp)

- **ہر بڑا جنریٹر، ایک ایپ** - Google Flow (تصویر + ویڈیو)، Google Vids، Google Pics، GPT Image 2، Meta Vibes اور Grok، ہر ایک اپنے صفحے پر ان ماڈلز اور تناسبات کے ساتھ جو وہ فراہم کنندہ سپورٹ کرتا ہے۔
- **بیچ کے لیے بنی** - پرومپٹ کی فہرست پیسٹ کریں (فی لائن ایک) یا `.txt`/Excel امپورٹ کریں؛ ہر پرومپٹ ایک قطار بن جاتا ہے۔ ریفرنس تصاویر فائل نام سے خودکار میچ ہو جاتی ہیں۔ اپنے منتخب کردہ متوازی تھریڈز کی تعداد کے ساتھ پوری فہرست چلائیں۔
- **پہلے شامل کریں، تیار ہونے پر چلائیں** - قطاریں ایک کیو میں جاتی ہیں؛ **Run / Pause / Stop** الگ الگ ہیں۔ جب تک آپ نہ کہیں کچھ شروع نہیں ہوتا، اور کیو مینیجر آپ کو دوبارہ ترتیب دینے اور معائنہ کرنے دیتا ہے۔
- **Gemini ✦ لوگو کا خودکار ہٹاؤ** - Google Pics کی تصاویر اور Google Vids کی ویڈیوز ڈاؤن لوڈ کے فوراً بعد صاف کر دی جاتی ہیں (لوگو رکھنا ہو تو **Gemini لوگو دکھائیں** آن کریں)۔ جن فائلوں میں لوگو نہیں ہوتا انہیں چھیڑا نہیں جاتا۔
- **کریکٹر لائبریری** - ایک کریکٹر ایک بار محفوظ کریں (ریفرنس تصویر + آواز + نوٹس) اور مناظر کو یکساں رکھنے کے لیے اسے Flow تصویر، Flow ویڈیو اور Google Vids کے پرومپٹس میں `@name` سے بلائیں۔
- **Workflow (node graph)** - نوڈز کو ایک پائپ لائن میں جوڑیں: پرومپٹ → تصویر → ویڈیو → آخری فریم نکالیں → اگلی ویڈیو، مزید ایک **ویڈیو جوڑیں** نوڈ جو دو کلپس کو ایک ٹرانزیشن کے ساتھ جوڑتا ہے۔
- **ویڈیو ٹولز** - ٹائم لائن پر ویڈیو ترمیم، سب ٹائٹل سے ہم آہنگ تصاویر کی سلائیڈ شو، ویڈیو کی تقسیم، فریمز نکالنا اور ویڈیو کا لوگو ہٹانا، سب ایپ کے اندر ہی۔
- آپ کی اپنی مشین پر **امیج اپ اسکیلر** اور آٹومیشن کے لیے ایک **Webhook API**۔
- **مضبوط** - نتائج تصدیق اور خودکار محفوظ ہوتے ہیں؛ سیشنز بحال ہوتے ہیں؛ ناکام قطاریں دوبارہ کوشش کرتی ہیں۔
- **لائٹ / ڈارک تھیم**، ٹیئر سے آگاہ UI، اور **15 زبانیں**۔

## چیزیں کہاں رہتی ہیں

| کیا | macOS | Windows |
|---|---|---|
| آؤٹ پٹ (تصاویر / ویڈیوز) | `~/Documents/G-Labs Studio/output` | `%USERPROFILE%\Documents\G-Labs Studio\output` |

## مسائل کا حل

**سب کچھ لاک ہے / خریداری کی اسکرین بار بار کھلتی ہے** - آپ کا پلان ختم ہو گیا، یا اکاؤنٹ کسی اور مشین پر سائن اِن ہو گیا۔ ٹیئر بیج (نیچے بائیں) چیک کریں اور تجدید کریں۔ Google Vids اور Google Pics کے لیے PLUS/MAX پلان درکار ہے؛ Webhook API کے لیے MAX درکار ہے۔

**Grok جنریشن کچھ نہیں کرتی** - Grok آپ کے `grok.com` ٹیب کے ذریعے چلتا ہے۔ **Auth Helper** براؤزر ایکسٹینشن انسٹال/فعال کریں (ترتیبات → Grok اکاؤنٹ) اور یقینی بنائیں کہ آپ grok.com پر لاگ اِن ہیں۔

**Google Pics کہتا ہے کوئی اکاؤنٹ نہیں ہے** - Pics، Google Vids کے اکاؤنٹس استعمال کرتا ہے۔ ترتیبات → **Google اکاؤنٹس** میں ایک شامل کریں۔

**کسی صفحے پر "فعال: 0 اکاؤنٹس"** - اس صفحے کے اکاؤنٹ ٹیب (ترتیبات) میں ایک اکاؤنٹ شامل یا دوبارہ فعال کریں، یا اس کا ٹوکن ختم ہو گیا ہے - **سب ریفریش کریں** دبائیں۔

**Windows اسے "Windows protected your PC" پر روک دیتا ہے** - **More info → Run anyway** پر کلک کریں۔ ایپ ابھی Microsoft سرٹیفکیٹ سے کوڈ سائن شدہ نہیں ہے، اس لیے اسے نشان زد کیا جاتا ہے - یہ وائرس نہیں ہے۔

**macOS کہتا ہے ایپ خراب ہے / کھولی نہیں جا سکتی** - یہ ابھی Apple کی طرف سے دستخط شدہ نہیں ہے۔ پہلی بار رائٹ کلک → **Open** کریں، یا `xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"` چلائیں۔

**اپ ڈیٹ انسٹال نہیں ہوئی** - تازہ ترین بلڈ دستی طور پر [Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest) سے ڈاؤن لوڈ کریں۔
