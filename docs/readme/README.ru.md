### Шаг 1 — Выберите правильную сборку для вашего компьютера

Скачайте последнюю версию из **[Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest)** и выберите файл, подходящий вашему компьютеру:

| 🍎 **Mac с чипом Apple (M1/M2/M3/M4)** | [macOS ARM](https://github.com/duckmartians/G-Labs-Studio/releases/latest/download/G-Labs-Studio-mac-arm64.dmg) | [macOS ARM](https://drive.google.com/drive/u/0/folders/1kfENU5CPWq_Djo641XvWiZERdKNun26Q) | Mac примерно с конца 2020 года |
| 🍎 **Mac с чипом Intel** | [macOS Intel](https://github.com/duckmartians/G-Labs-Studio/releases/latest/download/G-Labs-Studio-mac-intel.dmg) | [macOS Intel](https://drive.google.com/drive/u/0/folders/1qvFV8P5k6FpHfGfnwbL8CccrwXgGoYg0) | Более старые Mac (до 2020 года) |

**Не знаете, какой чип у вашего Mac?** Нажмите меню  (вверху слева) → **About This Mac**:
- Строка **Chip** со значением «Apple M1 / M2 / M3…» → скачивайте сборку **arm64**.
- Строка **Processor** со значением «Intel…» → скачивайте сборку **intel**.

> Сборка **Intel** всё равно запустится на Mac с чипом Apple (только медленнее), но сборка **arm64** **не откроется** на Intel Mac — поэтому выбирайте правильную.

### Шаг 2 — Установка

<details open>
<summary><b>🪟 На Windows</b></summary>

1. Откройте скачанный **`G-Labs-Studio-win.exe`**.
2. Если появится **«Windows protected your PC»** (SmartScreen): нажмите **More info** → **Run anyway**. *(Приложение пока не подписано сертификатом Microsoft, поэтому появляется предупреждение — это не вирус.)*
3. Нажмите **Yes** в запросе администратора (UAC) и пройдите установщик до конца.
4. Запустите его из **Start Menu** или ярлыком на **Desktop**.

</details>

<details open>
<summary><b>🍎 На macOS</b></summary>

1. Откройте скачанный **`.dmg`** и **перетащите G-Labs Studio в папку Applications**.
2. Откройте **Applications**, **щёлкните правой кнопкой** (или Control-клик) по **G-Labs Studio** → **Open** → ещё раз нажмите **Open** в диалоге. *(Приложение не подписано Apple, поэтому в **первый раз** его нужно открыть так; далее оно открывается обычно.)*
3. Если macOS пишет, что приложение **«повреждено / не может быть открыто»**, или нет кнопки Open, откройте **Terminal** и вставьте:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"
   ```
   Затем откройте приложение снова.

</details>

### Шаг 3 — Войдите и выберите план

**Вам нужен аккаунт G-Labs.** Откройте приложение, войдите через Google и выберите план. Планы (**BASIC / PLUS / MAX**) открывают разные инструменты и модели; купить можно прямо в приложении (банковский QR, PayPal или USDT). Один аккаунт работает **на одной машине одновременно** — вход в другом месте выходит из предыдущей машины. Значок в левом нижнем углу боковой панели показывает ваш текущий уровень. Нужно несколько устройств одновременно? Можно купить план **Team** (цена растёт с числом добавленных устройств).

> **Только что перешли со старой версии (G-Labs Automation)?** Новая версия **не** переносит ваши аккаунты. Нужно **заново войти во все аккаунты** (Google/Flow, ChatGPT, Meta…) в новой G-Labs Studio.

Приложение **обновляется само**: при запуске проверяет GitHub Releases и может скачать и установить новую версию прямо из приложения.

## Первый запуск

1. **Откройте приложение и войдите через Google.** Значок уровня (внизу слева: **BASIC / PLUS / MAX**) подтверждает ваш план.
2. **Подключите аккаунты для инструментов, которыми будете пользоваться** (**Настройки** → соответствующая вкладка аккаунтов):
   - **Аккаунты Flow** → Flow Изображение / Flow Видео
   - **Аккаунты Google** → **Google Vids** и **Google Pics** (обе страницы используют эти аккаунты Google; каждый аккаунт включается отдельно для видео Vids и для изображений Pics)
   - **Аккаунт ChatGPT** → GPT Image 2
   - **Аккаунт Vibes** → Meta Vibes
   - **Аккаунт Grok** → хранилища аккаунтов нет: эта вкладка проведёт вас через установку браузерного расширения **Auth Helper**, после чего Grok работает через вашу авторизованную вкладку `grok.com` в Chrome

   Каждая вкладка аккаунтов показывает **«Активно: N аккаунтов»** в заголовке, чтобы вы знали, сколько из них пригодны к использованию.
3. **Выберите страницу на левой боковой панели** и начните генерацию. У каждой страницы генерации один и тот же ритм: слева вводите или импортируете промпты, они попадают в **таблицу** справа, затем нажимаете **Run**.

В заголовке каждой страницы есть живая **строка состояния** — *Выполняется · В очереди · Готово · Ошибка · Аккаунты* — чтобы вы видели весь пакет одним взглядом. Нажмите **В очереди**, чтобы открыть менеджер очереди, **Аккаунты** — чтобы перейти к настройкам аккаунтов.

## Возможности

![G-Labs Studio](../screenshots/en/flow-image.webp)

- **Все крупные генераторы в одном приложении** — Google Flow (изображения + видео), Google Vids, Google Pics, GPT Image 2, Meta Vibes и Grok, каждый на своей странице с моделями и соотношениями сторон, которые поддерживает провайдер.
- **Создано для пакетной работы** — вставьте список промптов (по одному на строку) или импортируйте `.txt`/Excel; каждый промпт становится строкой. Референсные изображения автоматически сопоставляются по имени файла. Запускайте весь список с выбранным вами числом параллельных потоков.
- **Сначала добавьте, запустите когда готовы** — строки уходят в очередь; **Run / Pause / Stop** разделены. Ничего не запускается, пока вы не скажете, а менеджер очереди позволяет переупорядочивать и просматривать.
- **Автоматическое удаление логотипа Gemini ✦** — изображения Google Pics и видео Google Vids очищаются сразу после загрузки (включите **Показывать логотип Gemini**, чтобы сохранить его). Файлы без логотипа остаются нетронутыми.
- **Библиотека персонажей** — сохраните персонажа один раз (референсное изображение + голос + заметки) и вызывайте его через `@name` в промптах Flow Изображение, Flow Видео и Google Vids, чтобы сцены оставались согласованными.
- **Workflow (граф узлов)** — соедините узлы в конвейер: промпт → изображение → видео → извлечь последний кадр → следующее видео, плюс узел **Склеить видео**, который объединяет два клипа с переходом.
- **Видеоинструменты** — монтаж видео на таймлайне, слайд-шоу из изображений, синхронизированное с субтитрами, нарезка видео, извлечение кадров и удаление логотипа с видео — прямо в приложении.
- **Апскейл изображений** на вашем собственном компьютере и **Webhook API** для автоматизации.
- **Устойчивость** — результаты проверяются и автоматически сохраняются; сеансы восстанавливаются; неудавшиеся строки повторяются.
- **Светлая / тёмная тема**, интерфейс с учётом уровня и **15 языков**.

## Страницы

### 🖼 Flow Изображение — генерация изображений Google Flow

![Flow Изображение](../screenshots/en/flow-image.webp)

Пакетная генерация изображений с **Nano Banana Pro / 2 / 2 Lite**. Выберите модель, соотношение сторон и разрешение (**1K / 2K / 4K** — 2K/4K используют апскейлер модели), задайте, сколько строк выполняется одновременно, и задержку между ними. Вставьте промпты (или импортируйте файл), прикрепите референсные изображения к строкам (перетащите папку — они автоматически сопоставятся по имени файла) и используйте `@name`, чтобы подтянуть персонажа. Переключатель **Показывать логотип Veo / Gemini** (по умолчанию выключен) общий со страницей Flow Видео. **Run** отправляет весь список в очередь.

### 🎬 Flow Видео — Veo &amp; Omni Flash

![Flow Видео](../screenshots/en/flow-video.webp)

Три вкладки: **Текст / Кадр → Видео** (текстовый промпт или начальный/конечный кадры), **Изображение / Видео компоненты → Видео** (референсные изображения или референсное видео) и **Цепочка сцен → Видео**. Модели: **Veo 3.1 Fast / Lite / Quality** и **Omni Flash**. Выберите соотношение сторон, апскейл (720p / 1080p / 4K) и seed. Наведите курсор на **?** на панели вкладок для понятного объяснения различия кадров и компонентов.

### 📽 Google Vids

![Google Vids](../screenshots/en/vids.webp)

Создавайте видео с вашим аккаунтом Google на трёх вкладках: **Текст → Видео**, **Изображение → Видео** (одно начальное изображение) и **Компоненты → Видео** (до 3 изображений-компонентов). Выберите горизонтальную/вертикальную ориентацию, 720p / 1080p и длительность 3–10 секунд — или добавьте в промпт тег вроде `[4s]`, чтобы задать каждой строке свою длину. Готовые видео можно апскейлить до 1080p прямо из таблицы. У каждого аккаунта есть квота, измеряемая в секундах видео; добавьте больше аккаунтов, чтобы работать быстрее. Логотип Gemini ✦ на загруженных видео (720p / 1080p) удаляется автоматически, если вы не включите **Показывать логотип Gemini**.

### 🖼 Google Pics

![Google Pics](../screenshots/en/pics.webp)

Две вкладки: **Текст → Изображение** и **Изображение → Изображение** с **до 14 референсными изображениями** (персонажи, объекты, сцены, стиль). За каждый запуск Google возвращает 3–9 изображений; **Сохранять изображений за запуск** определяет, сколько оставить (1–4 или все). 10 соотношений сторон, включая 21:9, 3:2 и 5:4. Каждый запуск расходует 1 запуск Google Pics независимо от числа изображений; промпт, отклонённый политикой контента, ничего не стоит. Pics использует те же **Аккаунты Google**, что и Google Vids.

**Автоматическое удаление логотипа Gemini ✦:** у загруженных изображений Pics знак ✦ в правом нижнем углу удаляется сразу после загрузки с помощью карты логотипа, измеренной специально для Google Pics — наложение логотипа обращается, поэтому исходная текстура под ним восстанавливается, а не размывается. Изображения, на которых логотип не обнаружен, остаются как есть. Чтобы сохранить логотип, включите **Показывать логотип Gemini**.

### ✨ GPT Image 2 — OpenAI

![GPT Image 2](../screenshots/en/gpt-image.webp)

Генерируйте с OpenAI **GPT Image 2**, используя ваш аккаунт ChatGPT, с до 5 референсными изображениями. Выберите соотношение сторон (10 вариантов, включая 21:9, 4:5 и **custom** — где вы пишете соотношение прямо в промпте), качество, режим промпта, уровень рассуждения и веб-поиск.

### 🎨 Meta Vibes

![Meta Vibes](../screenshots/en/vibes.webp)

Создавайте изображения и видео в Meta Vibes на четырёх вкладках: **Текст → Изображение**, **Текст → Видео**, **Изображение → Изображение** (изображения персонажа / сцены / стиля) и **Изображение → Видео** (начальный / конечный кадр). Постановка в очередь и загрузка — автоматически.

### 🤖 Grok Imagen

![Grok Imagen](../screenshots/en/grok.webp)

Текст → Изображение, Изображение → Изображение, Текст → Видео и Изображение → Видео через Grok Imagine (ваша авторизованная вкладка `grok.com` через расширение Auth Helper). Для изображений доступно **8 соотношений сторон** (в т. ч. 4:3, 21:9, 5:2); видео рендерится в **480p / 720p / 1080p**. Изображение → Видео имеет два режима: **Первый кадр** (изображение открывает клип) и **Референсы** (до 14 направляющих изображений).

### 👤 Персонажи

![Персонажи](../screenshots/en/characters.webp)

Соберите многоразовый актёрский состав: референсное изображение, голос (один из готовых голосов Flow, с необязательным описанием подачи) и заметки о внешности/характере. Отметьте их через `@name` в промптах Flow Изображение, Flow Видео и Google Vids, и генерация сохранит эту идентичность (голос используется только Flow Видео; Google Vids использует изображение).

### 🔗 Workflow

![Workflow](../screenshots/en/workflow.webp)

Визуальный холст узлов. Кликните правой кнопкой по сокету узла — меню предложит только подходящие узлы; выберите один, и он соединится сам. Есть узлы для Flow Изображение, Flow Видео, Grok, Meta и GPT Image 2. Соедините промпт → изображение → видео → **Извлечь кадр** → следующее видео и используйте **Склеить видео**, чтобы объединить два клипа (обрежьте каждый конец, выберите переход). Сохраняйте/загружайте весь граф как файл `.json` (формат: [`WORKFLOW_JSON_SPEC.md`](../../WORKFLOW_JSON_SPEC.md)); **Run Flow** выполняет его от начала до конца.

### 🎞 Видеоинструменты

Пять вкладок на одной странице:

**Редактор видео** — таймлайн для видео, субтитров SRT и аудио: обрезка, разделение, перестановка, автоподгонка, затем экспорт одного готового видео.

![Редактор видео](../screenshots/en/vt-video.webp)

**Слайд-шоу из изображений по субтитрам** — загрузите изображения и файл `.srt`; каждое изображение автоматически сопоставляется со строкой субтитров, с эффектами движения, наложениями и оформлением субтитров.

![Слайд-шоу из изображений по субтитрам](../screenshots/en/vt-slideshow.webp)

**Разрезать видео на фрагменты** — по числу частей, фиксированной или случайной длине, списку временных меток или списку диапазонов A–B; один файл или целый пакет, с ускорением на GPU, если доступно.

![Разрезать видео на фрагменты](../screenshots/en/vt-slicer.webp)

**Извлечь кадры из видео** — по общему количеству, временному интервалу, интервалу кадров или движению; один файл или целая папка.

![Извлечь кадры из видео](../screenshots/en/vt-extractor.webp)

**Удалить логотип с видео** — удаляет логотип ✦ с видео Google Vids в 720p и 1080p (горизонтальных или вертикальных), с предпросмотром до/после в приложении. Видео без логотипа пропускаются; оригиналы сохраняются, а результаты записываются как `<имя>_nologo.mp4`.

![Удалить логотип с видео](../screenshots/en/vt-logo.webp)

### 🔍 Апскейл изображений

![Апскейл изображений](../screenshots/en/upscaler.webp)

Увеличивайте и повышайте резкость изображений прямо на своём компьютере — добавьте отдельные изображения или целую папку, выберите ИИ-модель (Real-ESRGAN, UltraSharp, Remacri…) и масштаб 2x–8x, следите за прогрессом по каждой строке и сравнивайте до/после.

### 🌐 Webhook API

![Webhook API](../screenshots/en/webhook.webp)

Превратите приложение в локальный сервер автоматизации (план MAX), чтобы n8n, Make, Zapier, скрипты или ИИ-агенты могли отправлять задачи в очередь приложения. Запустите его, скопируйте свой API-ключ и отправляйте задачи POST на `/api/image/generate`, `/api/video/generate`, `/api/grok/generate`, `/api/meta/generate`, `/api/openai/generate` или `/api/upscale/generate`, затем опрашивайте `/api/status/<id>`. На странице перечислены все модели и поддерживаемые ими соотношения сторон. Полная схема: [`WEBHOOK_INTEGRATION.en.md`](../../WEBHOOK_INTEGRATION.en.md).

| Вывод (изображения / видео) | `~/Documents/G-Labs Studio/output` | `%USERPROFILE%\Documents\G-Labs Studio\output` |
| Настройки, сеансы, аккаунты, персонажи | `~/Library/Application Support/G-Labs Studio` | `%APPDATA%\G-Labs Studio` |

У каждой страницы своя подпапка внутри `output` (по одной папке поменьше на каждый запуск); папку сохранения можно изменить на каждой странице. Ваши настройки, списки промптов, сеансы, библиотека персонажей и список аккаунтов сохраняются и восстанавливаются при следующем открытии приложения.

## Устранение неполадок

**Всё заблокировано / постоянно открывается экран покупки** — ваш план истёк, или аккаунт вошёл на другой машине. Проверьте значок уровня (внизу слева) и продлите. Google Vids и Google Pics требуют план PLUS/MAX; Webhook API требует MAX.

**Генерация Grok ничего не делает** — Grok работает через вашу вкладку `grok.com`. Установите/включите браузерное расширение **Auth Helper** (Настройки → Аккаунт Grok) и убедитесь, что вы вошли на grok.com.

**Google Pics сообщает, что аккаунта нет** — Pics использует аккаунты Google Vids. Добавьте аккаунт в Настройки → **Аккаунты Google**.

**«Активно: 0 аккаунтов» на странице** — добавьте или снова включите аккаунт во вкладке аккаунтов этой страницы (Настройки), либо истёк его токен — нажмите **Обновить все**.

**Windows блокирует запуск сообщением «Windows protected your PC»** — нажмите **More info → Run anyway**. Приложение пока не подписано сертификатом Microsoft, поэтому оно помечается — это не вирус.

**macOS сообщает, что приложение повреждено / не может быть открыто** — оно пока не подписано Apple. Откройте через правый клик → **Open** в первый раз или выполните `xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"`.

**Обновление не установилось** — скачайте последнюю сборку вручную из раздела [Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest).
