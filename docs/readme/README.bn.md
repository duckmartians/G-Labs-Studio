## ইনস্টল

সর্বশেষ বিল্ড **[Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest)** থেকে ডাউনলোড করুন:

| প্ল্যাটফর্ম | ফাইল |
|---|---|
| 🪟 **Windows** | `G-Labs-Studio-v<version>-win.exe` — ইনস্টলার চালান (admin/UAC) |
| 🍎 **macOS (Apple Silicon)** | `G-Labs-Studio-v<version>-mac-arm64.dmg` |
| 🍎 **macOS (Intel)** | `G-Labs-Studio-v<version>-mac-intel.dmg` |

**macOS-এ প্রথমবার চালু** — অ্যাপটি Apple দ্বারা সাইন করা নয়, তাই macOS একে কোয়ারেন্টাইন করে। প্রথমবার এটি **রাইট-ক্লিক → Open** দিয়ে খুলুন, অথবা Terminal থেকে ফ্ল্যাগটি সরান:

```bash
xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"
```

**আপনার একটি G-Labs অ্যাকাউন্ট প্রয়োজন।** অ্যাপটি খুলুন, Google দিয়ে সাইন ইন করুন এবং একটি প্ল্যান বেছে নিন। প্ল্যানগুলি (**FREE / PLUS / MAX**) বিভিন্ন টুল এবং মডেল আনলক করে; আপনি অ্যাপের ভেতর থেকেই একটি কিনতে পারেন (ব্যাংক QR, PayPal, বা USDT)। একটি অ্যাকাউন্ট **এক সময়ে একটি মেশিনে** চলে — অন্য কোথাও সাইন ইন করলে আগের মেশিন সাইন আউট হয়ে যায়। সাইডবারের নিচে-বাঁয়ের ব্যাজ আপনার বর্তমান টিয়ার দেখায়।

অ্যাপটি **নিজেকে আপডেট করে**: চালুর সময় এটি GitHub Releases পরীক্ষা করে এবং অ্যাপের ভেতর থেকেই নতুন সংস্করণ ডাউনলোড ও ইনস্টল করতে পারে।

## প্রথমবার চালানো

1. **অ্যাপটি খুলুন এবং Google দিয়ে সাইন ইন করুন।** টিয়ার ব্যাজ (নিচে-বাঁয়ে) আপনার প্ল্যান নিশ্চিত করে।
2. **আপনি যে টুলগুলি ব্যবহার করবেন সেগুলির অ্যাকাউন্ট সংযোগ করুন** (Settings → সংশ্লিষ্ট অ্যাকাউন্ট ট্যাব):
   - **Google** অ্যাকাউন্ট → Flow Image / Flow Video
   - **ChatGPT** অ্যাকাউন্ট → GPT Image 2
   - **Meta** অ্যাকাউন্ট → Meta Media
   - **Grok** → companion ব্রাউজার এক্সটেনশন (Auth Helper)-এর মাধ্যমে আপনার লগ-ইন করা `grok.com` ট্যাব দিয়ে চলে — কোনো অ্যাকাউন্ট পুল নেই
   প্রতিটি অ্যাকাউন্ট ট্যাব তার টাইটেল বারে **"Active: N accounts"** দেখায় যাতে আপনি জানেন কতগুলি ব্যবহারযোগ্য।
3. **বাঁ সাইডবার থেকে একটি পেজ বেছে নিন** এবং জেনারেট করা শুরু করুন। প্রতিটি জেনারেশন পেজের একই ছন্দ: বাঁ দিকে প্রম্পট টাইপ বা ইম্পোর্ট করুন, সেগুলি ডান দিকে একটি **টেবিল**-এ আসে, তারপর **Run** চাপুন।

প্রতিটি পেজ হেডারে একটি লাইভ **status bar** থাকে — *Running · Queued · Done · Failed · Accounts* — যাতে আপনি এক নজরে ব্যাচটি দেখতে পারেন। কিউ ম্যানেজার খুলতে **Queued**-এ ক্লিক করুন, অ্যাকাউন্ট সেটিংসে যেতে **Accounts**-এ।

## বৈশিষ্ট্য

- **প্রতিটি প্রধান জেনারেটর, একটি অ্যাপ** — Google Flow (ছবি + ভিডিও), Grok Imagine, Meta AI (vibes.ai) এবং OpenAI GPT Image 2, প্রতিটি তার নিজস্ব পেজে সেই প্রোভাইডার যে মডেল ও অনুপাত সমর্থন করে সেগুলির সাথে।
- **ডিজাইন থেকেই ব্যাচ** — প্রম্পটের একটি তালিকা পেস্ট করুন (প্রতি লাইনে একটি) বা একটি `.txt`/Excel ফাইল ইম্পোর্ট করুন; প্রতিটি একটি সারি হয়ে যায়। রেফারেন্স ছবিগুলি ফাইলনাম দিয়ে স্বয়ংক্রিয়ভাবে মিলে যায়। পুরো তালিকাটি আপনার বেছে নেওয়া concurrency দিয়ে চালান।
- **আগে যোগ করুন, প্রস্তুত হলে চালান** — সারিগুলি একটি কিউতে যায়; **Run / Pause / Stop** আলাদা। আপনি না বলা পর্যন্ত কিছুই শুরু হয় না, এবং একটি কিউ ম্যানেজার আপনাকে পুনর্বিন্যাস ও পরিদর্শন করতে দেয়।
- **ক্যারেক্টার লাইব্রেরি** — একটি ক্যারেক্টার একবার সংরক্ষণ করুন (রেফারেন্স ছবি + তার নিজস্ব ভয়েস + নোট) এবং `@name` দিয়ে যেকোনো প্রম্পটে ফেলুন; ভিডিও সেই ক্যারেক্টারের চেহারা ও ভয়েস বজায় রাখে।
- **Workflow (নোড গ্রাফ)** — নোডগুলিকে একটি পাইপলাইনে সংযুক্ত করুন: প্রম্পট → ছবি → ভিডিও → শেষ ফ্রেম বের করুন → পরবর্তী ভিডিও, সাথে একটি **Merge Video** নোড যা দুটি ক্লিপকে ট্রিম ও ট্রানজিশন (crossfade, wipe, slide, dissolve…) দিয়ে জোড়ে। ব্যাচ নোডগুলি প্রতি প্রম্পট বা প্রতি ছবির জন্য পুরো শৃঙ্খলটি লুপ করে।
- **Webhook API** — একটি লোকাল REST সার্ভার যাতে স্ক্রিপ্ট ও AI এজেন্ট image/video/Grok/Meta/OpenAI জব জমা দিতে এবং ফলাফলের জন্য পোল করতে পারে।
- ফিনিশিংয়ের জন্য **Image Upscaler** এবং একটি **Video Editor** (কাট, স্টিচ, স্লাইডশো)।
- **স্থিতিস্থাপক** — ফলাফল যাচাই ও স্বয়ংক্রিয়ভাবে সংরক্ষিত হয়; সেশন পুনরুদ্ধার হয়; ব্যর্থ সারি পুনরায় চেষ্টা করে।
- **ডার্ক / লাইট থিম**, টিয়ার-সচেতন UI, এবং **১৫টি ভাষা**।

## পেজসমূহ

### 🖼 Flow Image — Google Flow ছবি জেনারেশন

![Flow Image](../screenshots/01-image.png)

**Nano Banana Pro / 2 / Lite** দিয়ে ছবি ব্যাচ-জেনারেট করুন। মডেল, অ্যাসপেক্ট রেশিও এবং রেজোলিউশন বেছে নিন (**1K / 2K / 4K** — 2K/4K মডেলের আপস্কেলার ব্যবহার করে), একসাথে কতগুলি সারি চলবে এবং সেগুলির মধ্যে বিলম্ব সেট করুন। প্রম্পট পেস্ট করুন (বা একটি ফাইল ইম্পোর্ট করুন), প্রতি সারিতে রেফারেন্স ছবি যুক্ত করুন (একটি ফোল্ডার টেনে আনুন, সেগুলি ফাইলনাম দিয়ে স্বয়ংক্রিয়ভাবে মিলে যায়), এবং ক্যারেক্টার আনতে `@name` ব্যবহার করুন। **Run** পুরো তালিকাটি কিউতে পাঠায়।

### 🎬 Flow Video — Veo এবং Omni Flash

![Flow Video](../screenshots/02-flow-video.png)

তিনটি ট্যাব: **Text / Frames → Video** (একটি টেক্সট প্রম্পট, বা একটি স্টার্ট/এন্ড ফ্রেম), **Image / Video ingredients → Video** (রেফারেন্স ছবি বা একটি রেফারেন্স ভিডিও), এবং **Scene stitch → Video**। মডেল: **Veo 3.1 Fast / Lite / Quality** এবং **Omni Flash**। অ্যাসপেক্ট রেশিও, আপস্কেল (720p / 1080p / 4K) এবং seed বেছে নিন। frames বনাম ingredients-এর সহজ-ভাষায় ব্যাখ্যার জন্য ট্যাব বারের **?**-এ হোভার করুন।

### 🤖 Grok Media — Grok Imagine

![Grok Media](../screenshots/03-grok.png)

Grok Imagine-এর মাধ্যমে টেক্সট-টু-ইমেজ, ইমেজ-টু-ইমেজ, টেক্সট-টু-ভিডিও এবং ইমেজ-টু-ভিডিও (Auth Helper এক্সটেনশনের মাধ্যমে আপনার লগ-ইন করা `grok.com` ট্যাব)। ছবিগুলি **৮টি অ্যাসপেক্ট রেশিও** দেয় (4:3, 21:9, 5:2 সহ); ভিডিও **480p / 720p / 1080p**-এ জেনারেট হয়। ইমেজ-টু-ভিডিও-র দুটি মোড: **First frame** (ছবিটি ক্লিপ শুরু করে) এবং **Reference** (সর্বোচ্চ ১৪টি নির্দেশক ছবি)।

### 🎨 Meta Media — Meta AI (vibes.ai)

![Meta Media](../screenshots/04-meta.png)

Meta AI-এর মাধ্যমে ছবি ও ভিডিও জেনারেশন। মোড: টেক্সট-টু-ইমেজ, ইমেজ-টু-ইমেজ (Character / Scene / Style কম্পোনেন্ট), টেক্সট-টু-ভিডিও এবং ইমেজ-টু-ভিডিও (স্টার্ট / এন্ড ফ্রেম)।

### ✨ GPT Image 2 — OpenAI

![GPT Image 2](../screenshots/05-openai.png)

আপনার ChatGPT অ্যাকাউন্ট ব্যবহার করে OpenAI **GPT Image 2** দিয়ে জেনারেট করুন, সর্বোচ্চ ৫টি রেফারেন্স ছবি সহ। রেশিও বেছে নিন (১০টি অপশন, যার মধ্যে 21:9, 4:5 এবং **custom** রয়েছে — যেখানে আপনি রেশিওটি প্রম্পটে লেখেন), গুণমান, প্রম্পট মোড, reasoning effort এবং ওয়েব সার্চ।

### 🔍 Image Upscaler

![Image Upscaler](../screenshots/06-upscaler.png)

ছবির একটি ফোল্ডার লোকালি আপস্কেল করুন — লক্ষ্য বেছে নিন এবং কিউটি প্রসেস হতে দিন, প্রতি-সারি অগ্রগতি ও স্ট্যাটাস (processing / done / error) সহ।

### 👤 Characters

![Characters](../screenshots/07-character.png)

পুনঃব্যবহারযোগ্য ক্যারেক্টারের একটি লাইব্রেরি তৈরি করুন: একটি রেফারেন্স ছবি, একটি ঐচ্ছিক কাস্টম ভয়েস, এবং চেহারা/ব্যক্তিত্ব নোট। যেকোনো Flow প্রম্পটে `@name` দিয়ে তাদের ট্যাগ করুন এবং জেনারেশন সেই পরিচয় বজায় রাখবে।

### 🔗 Workflow

![Workflow](../screenshots/08-workflow.png)

একটি ভিজ্যুয়াল নোড ক্যানভাস। একটি নোডের সকেটে রাইট-ক্লিক করুন এবং মেনু কেবল সেই নোডগুলি দেয় যা মানানসই — একটি বেছে নিন এবং তা স্বয়ংক্রিয়ভাবে সংযুক্ত হয়। প্রম্পট → generate → ভিডিও → **Extract Frame** → পরবর্তী ভিডিও শৃঙ্খলিত করুন, এবং দুটি ক্লিপ জোড়তে **Merge Video** ব্যবহার করুন (প্রতিটি প্রান্ত ট্রিম করুন, একটি ট্রানজিশন বেছে নিন)। পুরো গ্রাফটি একটি `.json` ফাইল হিসেবে সংরক্ষণ/লোড করুন; **Run Flow** এটি শুরু থেকে শেষ পর্যন্ত চালায়।

### 🌐 Webhook API

![Webhook API](../screenshots/09-webhook.png)

অ্যাপটিকে একটি লোকাল অটোমেশন সার্ভারে পরিণত করুন। এটি স্টার্ট করুন, আপনার API key কপি করুন, এবং `/api/image/generate`, `/api/video/generate`, `/api/grok/generate`, `/api/meta/generate` বা `/api/openai/generate`-তে জব POST করুন, তারপর `/api/status/<id>` পোল করুন। পেজটি প্রতিটি মডেল ও তার সমর্থিত অ্যাসপেক্ট রেশিও তালিকাভুক্ত করে। সম্পূর্ণ স্কিমা: [`docs/WEBHOOK_INTEGRATION.en.md`](../WEBHOOK_INTEGRATION.en.md)।

|---|---|---|
| আউটপুট (ছবি / ভিডিও) | `~/Documents/G-Labs Studio` | `%USERPROFILE%\Documents\G-Labs Studio` |
| সেটিংস, সেশন, অ্যাকাউন্ট | `~/Library/Application Support/G-Labs Studio` | `%APPDATA%\G-Labs Studio` |

আপনার সেটিংস, প্রম্পট তালিকা, সেশন, ক্যারেক্টার লাইব্রেরি এবং অ্যাকাউন্ট তালিকা সংরক্ষিত হয় এবং পরের বার অ্যাপ খুললে পুনরুদ্ধার হয়।

## সমস্যা সমাধান

**সবকিছু লক / কেনার স্ক্রিন বারবার খোলে** — আপনার প্ল্যানের মেয়াদ শেষ হয়েছে, অথবা অ্যাকাউন্টটি অন্য মেশিনে সাইন ইন হয়েছে। টিয়ার ব্যাজ (নিচে-বাঁয়ে) পরীক্ষা করুন এবং নবায়ন করুন।

**একটি Grok জেনারেশন কিছুই করে না** — Grok আপনার `grok.com` ট্যাব দিয়ে চলে। **Auth Helper** ব্রাউজার এক্সটেনশন ইনস্টল/সক্রিয় করুন (Settings → Grok) এবং নিশ্চিত করুন আপনি grok.com-এ লগ-ইন আছেন।

**একটি পেজে "Active: 0 accounts"** — সেই পেজের অ্যাকাউন্ট ট্যাবে (Settings) একটি অ্যাকাউন্ট যোগ করুন বা পুনরায় সক্রিয় করুন, অথবা তার টোকেনের মেয়াদ শেষ হয়েছে — **Refresh all** চাপুন।

**macOS বলে অ্যাপটি damaged / খোলা যাচ্ছে না** — এটি Apple দ্বারা সাইন করা নয়। প্রথমবার রাইট-ক্লিক → **Open** করুন, অথবা `xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"` চালান।

**একটি আপডেট ইনস্টল হয় না** — সর্বশেষ বিল্ডটি [Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest) থেকে ম্যানুয়ালি ডাউনলোড করুন।
