### ขั้นที่ 2 — ติดตั้ง

<details open>
<summary><b>🪟 บน Windows</b></summary>

1. เปิดไฟล์ **`G-Labs-Studio-win.exe`** ที่ดาวน์โหลดมา
2. ถ้าขึ้น **“Windows protected your PC”** (SmartScreen): คลิก **More info** → **Run anyway** *(แอปยังไม่ได้เซ็นด้วยใบรับรองของ Microsoft จึงถูกเตือน — ไม่ใช่ไวรัส)*
3. คลิก **Yes** ที่หน้าต่างสิทธิ์ผู้ดูแล (UAC) แล้วทำตามตัวติดตั้งจนเสร็จ
4. เปิดจาก **Start Menu** หรือทางลัดบน **Desktop**

</details>

<details open>
<summary><b>🍎 บน macOS</b></summary>

1. เปิดไฟล์ **`.dmg`** ที่ดาวน์โหลดมา แล้ว **ลาก G-Labs Studio ไปไว้ในโฟลเดอร์ Applications**
2. ไปที่ **Applications**, **คลิกขวา** (หรือกด Control แล้วคลิก) ที่ **G-Labs Studio** → **Open** → คลิก **Open** อีกครั้งในกล่องโต้ตอบ *(แอปยังไม่ได้เซ็นโดย Apple จึงต้องเปิดแบบนี้ใน **ครั้งแรก**; หลังจากนั้นเปิดได้ตามปกติ)*
3. ถ้า macOS แจ้งว่าแอป **“เสียหาย / เปิดไม่ได้”** หรือไม่มีปุ่ม Open ให้เปิด **Terminal** แล้ววาง:
   ```bash
   xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"
   ```
   จากนั้นเปิดแอปอีกครั้ง

</details>

## การใช้งานครั้งแรก

1. **เปิดแอปและลงชื่อเข้าใช้ด้วย Google** ป้ายระดับ (มุมล่างซ้าย: **BASIC / PLUS / MAX**) ยืนยันแพ็กเกจของคุณ
2. **เชื่อมต่อบัญชีสำหรับเครื่องมือที่คุณจะใช้** (**การตั้งค่า** → แท็บบัญชีที่ตรงกัน):
   - **บัญชี Flow** → Flow รูปภาพ / Flow วิดีโอ
   - **บัญชี Google** → **Google Vids** และ **Google Pics** (ทั้งสองหน้าใช้บัญชี Google ชุดนี้ร่วมกัน แต่ละบัญชีเปิดใช้แยกกันสำหรับวิดีโอ Vids และภาพ Pics)
   - **บัญชี ChatGPT** → GPT Image 2
   - **บัญชี Vibes** → Meta Vibes
   - **บัญชี Grok** → ไม่มีที่เก็บบัญชี: แท็บนี้จะแนะนำให้คุณติดตั้งส่วนขยายเบราว์เซอร์ **Auth Helper** จากนั้น Grok จะทำงานผ่านแท็บ `grok.com` ที่คุณลงชื่อเข้าใช้ไว้ใน Chrome

   แท็บบัญชีแต่ละแท็บแสดง **"ใช้งาน: N บัญชี"** บนแถบชื่อ เพื่อให้คุณรู้ว่ามีกี่บัญชีที่ใช้งานได้
3. **เลือกหน้าจากแถบด้านข้างซ้าย** แล้วเริ่มสร้าง ทุกหน้าการสร้างมีจังหวะเดียวกัน: พิมพ์หรือนำเข้าพรอมป์ทางซ้าย พวกมันจะไปอยู่ใน **ตาราง** ทางขวา จากนั้นกด **Run**

ส่วนหัวของทุกหน้ามี **แถบสถานะ** แบบเรียลไทม์ — *กำลังทำงาน · คิว · เสร็จ · ล้มเหลว · บัญชี* — เพื่อให้คุณเห็นทั้งชุดงานได้ในพริบตา คลิก **คิว** เพื่อเปิดตัวจัดการคิว คลิก **บัญชี** เพื่อไปยังการตั้งค่าบัญชี

## คุณสมบัติ

![G-Labs Studio](../screenshots/en/flow-image.webp)

- **ตัวสร้างรายใหญ่ทุกเจ้า ในแอปเดียว** — Google Flow (ภาพ + วิดีโอ), Google Vids, Google Pics, GPT Image 2, Meta Vibes และ Grok แต่ละตัวอยู่บนหน้าของตัวเองพร้อมโมเดลและอัตราส่วนที่ผู้ให้บริการนั้นรองรับ
- **สร้างมาเพื่องานเป็นชุด** — วางรายการพรอมป์ (บรรทัดละหนึ่ง) หรือนำเข้า `.txt`/Excel แต่ละพรอมป์จะกลายเป็นหนึ่งแถว ภาพอ้างอิงจับคู่อัตโนมัติตามชื่อไฟล์ รันทั้งรายการด้วยจำนวนเธรดขนานที่คุณเลือก
- **เพิ่มก่อน รันเมื่อพร้อม** — แถวต่าง ๆ เข้าสู่คิว **Run / Pause / Stop** แยกกัน ไม่มีอะไรเริ่มจนกว่าคุณจะสั่ง และตัวจัดการคิวให้คุณจัดลำดับใหม่และตรวจสอบได้
- **ลบโลโก้ Gemini ✦ อัตโนมัติ** — ภาพ Google Pics และวิดีโอ Google Vids จะถูกล้างโลโก้ทันทีหลังดาวน์โหลด (เปิด **แสดงโลโก้ Gemini** หากต้องการเก็บโลโก้ไว้) ไฟล์ที่ไม่มีโลโก้จะไม่ถูกแตะต้อง
- **คลังตัวละคร** — บันทึกตัวละครครั้งเดียว (ภาพอ้างอิง + เสียง + บันทึก) แล้วเรียกใช้ด้วย `@name` ในพรอมป์ของ Flow รูปภาพ, Flow วิดีโอ และ Google Vids เพื่อให้ฉากต่าง ๆ สอดคล้องกัน
- **เวิร์กโฟลว์ (โหนดกราฟ)** — เชื่อมโหนดเข้าเป็นไปป์ไลน์: พรอมป์ → ภาพ → วิดีโอ → ดึงเฟรมสุดท้าย → วิดีโอถัดไป พร้อมโหนด **ต่อวิดีโอ** ที่รวมสองคลิปด้วยทรานซิชัน
- **เครื่องมือวิดีโอ** — ตัดต่อวิดีโอแบบไทม์ไลน์ สไลด์โชว์รูปภาพที่ซิงก์กับคำบรรยาย แบ่งวิดีโอ แยกเฟรม และลบโลโก้วิดีโอ ได้ภายในแอปเลย
- **อัปสเกลภาพ** บนเครื่องของคุณเอง และ **Webhook API** สำหรับงานอัตโนมัติ
- **ทนทาน** — ผลลัพธ์ถูกตรวจสอบและบันทึกอัตโนมัติ เซสชันถูกกู้คืน แถวที่ล้มเหลวลองใหม่
- **ธีมสว่าง / มืด**, UI ที่รับรู้ระดับ (tier) และ **15 ภาษา**

### 🖼 Flow รูปภาพ — การสร้างภาพด้วย Google Flow

![Flow รูปภาพ](../screenshots/en/flow-image.webp)

สร้างภาพเป็นชุดด้วย **Nano Banana Pro / 2 / 2 Lite** เลือกโมเดล อัตราส่วนภาพ และความละเอียด (**1K / 2K / 4K** — 2K/4K ใช้ตัวอัปสเกลของโมเดล) ตั้งค่าว่าจะรันกี่แถวพร้อมกันและดีเลย์ระหว่างแถว วางพรอมป์ (หรือนำเข้าไฟล์) แนบภาพอ้างอิงต่อแถว (วางโฟลเดอร์เข้ามาแล้วจะจับคู่อัตโนมัติตามชื่อไฟล์) และใช้ `@name` เพื่อดึงตัวละครเข้ามา สวิตช์ **แสดงโลโก้ Veo / Gemini** (ปิดเป็นค่าเริ่มต้น) ใช้ร่วมกับหน้า Flow วิดีโอ **Run** จะส่งทั้งรายการเข้าคิว

### 🎬 Flow วิดีโอ — Veo &amp; Omni Flash

![Flow วิดีโอ](../screenshots/en/flow-video.webp)

สามแท็บ: **ข้อความ / เฟรม → วิดีโอ** (พรอมป์ข้อความ หรือเฟรมเริ่ม/จบ), **ภาพ / วิดีโอส่วนประกอบ → วิดีโอ** (ภาพอ้างอิงหรือวิดีโออ้างอิง) และ **ลำดับฉาก → วิดีโอ** โมเดล: **Veo 3.1 Fast / Lite / Quality** และ **Omni Flash** เลือกอัตราส่วนภาพ อัปสเกล (720p / 1080p / 4K) และ seed วางเมาส์เหนือ **?** บนแถบแท็บเพื่อดูคำอธิบายภาษาง่าย ๆ ว่าเฟรมต่างจากส่วนประกอบอย่างไร

### 📽 Google Vids

![Google Vids](../screenshots/en/vids.webp)

สร้างวิดีโอด้วยบัญชี Google ของคุณในสามแท็บ: **ข้อความ → วิดีโอ**, **รูปภาพ → วิดีโอ** (ภาพเปิดหนึ่งภาพ) และ **องค์ประกอบ → วิดีโอ** (ภาพองค์ประกอบได้สูงสุด 3 ภาพ) เลือกแนวนอน/แนวตั้ง 720p / 1080p และความยาว 3–10 วินาที — หรือใส่แท็กอย่าง `[4s]` ในพรอมป์เพื่อกำหนดความยาวของแต่ละแถวเอง วิดีโอที่เสร็จแล้วอัปสเกลเป็น 1080p ได้จากตารางโดยตรง แต่ละบัญชีมีโควตาที่วัดเป็นวินาทีของวิดีโอ เพิ่มบัญชีมากขึ้นเพื่อรันได้เร็วขึ้น โลโก้ Gemini ✦ บนวิดีโอที่ดาวน์โหลด (720p / 1080p) จะถูกลบโดยอัตโนมัติ เว้นแต่คุณเปิด **แสดงโลโก้ Gemini**

### 🖼 Google Pics

![Google Pics](../screenshots/en/pics.webp)

สองแท็บ: **ข้อความ → ภาพ** และ **ภาพ → ภาพ** พร้อม **ภาพอ้างอิงได้สูงสุด 14 ภาพ** (ตัวละคร วัตถุ ฉาก สไตล์) ในแต่ละรอบ Google จะส่งภาพกลับมา 3–9 ภาพ **เก็บภาพต่อรอบ** กำหนดว่าจะเก็บไว้กี่ภาพ (1–4 หรือทั้งหมด) มี 10 อัตราส่วนภาพ รวมถึง 21:9, 3:2 และ 5:4 ทุกรอบใช้ 1 รอบของ Google Pics ไม่ว่าจะได้ภาพกี่ภาพ พรอมป์ที่ถูกนโยบายเนื้อหาปฏิเสธจะไม่เสียอะไร Pics ใช้ **บัญชี Google** ร่วมกับ Google Vids

**ลบโลโก้ Gemini ✦ อัตโนมัติ:** ภาพ Pics ที่ดาวน์โหลดจะถูกลบเครื่องหมาย ✦ ที่มุมล่างขวาทันทีหลังดาวน์โหลด โดยใช้แผนที่โลโก้ที่วัดมาเฉพาะสำหรับ Google Pics — การผสมของโลโก้จะถูกย้อนกลับ ทำให้พื้นผิวเดิมที่อยู่ข้างใต้ถูกกู้คืนแทนที่จะถูกเบลอ ภาพที่ตรวจไม่พบโลโก้จะคงไว้ตามเดิม หากต้องการเก็บโลโก้ ให้เปิด **แสดงโลโก้ Gemini**

## ไฟล์ต่าง ๆ อยู่ที่ไหน

| อะไร | macOS | Windows |
|---|---|---|
| เอาต์พุต (ภาพ / วิดีโอ) | `~/Documents/G-Labs Studio/output` | `%USERPROFILE%\Documents\G-Labs Studio\output` |

แต่ละหน้ามีโฟลเดอร์ย่อยของตัวเองภายใน `output` (โฟลเดอร์ย่อยลงไปอีกหนึ่งโฟลเดอร์ต่อรอบ) คุณเปลี่ยนโฟลเดอร์บันทึกได้ในแต่ละหน้า การตั้งค่า รายการพรอมป์ เซสชัน คลังตัวละคร และรายการบัญชีของคุณจะถูกบันทึกและกู้คืนในครั้งถัดไปที่คุณเปิดแอป

## การแก้ปัญหา

**ทุกอย่างถูกล็อก / หน้าจอซื้อเปิดขึ้นมาเรื่อย ๆ** — แพ็กเกจของคุณหมดอายุ หรือบัญชีถูกลงชื่อเข้าใช้บนเครื่องอื่น ตรวจสอบป้ายระดับ (มุมล่างซ้าย) แล้วต่ออายุ Google Vids และ Google Pics ต้องใช้แพ็กเกจ PLUS/MAX ส่วน Webhook API ต้องใช้ MAX

**การสร้าง Grok ไม่ทำอะไรเลย** — Grok ทำงานผ่านแท็บ `grok.com` ของคุณ ติดตั้ง/เปิดใช้งานส่วนขยายเบราว์เซอร์ **Auth Helper** (การตั้งค่า → บัญชี Grok) และตรวจสอบว่าคุณลงชื่อเข้าใช้ grok.com อยู่

**Google Pics แจ้งว่าไม่มีบัญชี** — Pics ใช้บัญชีของ Google Vids เพิ่มบัญชีได้ที่ การตั้งค่า → **บัญชี Google**

**"ใช้งาน: 0 บัญชี" บนหน้าหนึ่ง** — เพิ่มหรือเปิดใช้งานบัญชีอีกครั้งในแท็บบัญชีของหน้านั้น (การตั้งค่า) หรือโทเคนหมดอายุ — กด **รีเฟรชทั้งหมด**

**Windows บล็อกที่ "Windows protected your PC"** — คลิก **More info → Run anyway** แอปยังไม่ได้เซ็นโค้ดด้วยใบรับรองของ Microsoft จึงถูกตั้งค่าสถานะ — ไม่ใช่ไวรัส

**macOS บอกว่าแอปเสียหาย / เปิดไม่ได้** — แอปยังไม่ได้เซ็นโดย Apple คลิกขวา → **Open** ในครั้งแรก หรือรัน `xattr -dr com.apple.quarantine "/Applications/G-Labs Studio.app"`

**อัปเดตติดตั้งไม่สำเร็จ** — ดาวน์โหลดบิลด์ล่าสุดด้วยตนเองจาก [Releases](https://github.com/duckmartians/G-Labs-Studio/releases/latest)
